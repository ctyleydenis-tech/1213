FUN RUSSIA HUD v2 — что нужно обновить на сервере (Pawn / samp-cef)
====================================================================

Этот HUD полностью событийный: он ничего не запрашивает сам, а только
слушает cef-события. Всё, что видно на экране, должно приходить с
серверной стороны через cef_emit_event(playerid, "имя_события", ...).

Ниже — полный список событий, которые ждёт hud.js, и когда их слать.


1) hud:level  (лвл + опыт)
   cef_emit_event(playerid, "hud:level", lvl, expCur, expMax);
   Слать: при заходе в игру + при любом изменении lvl/exp.

2) hud:online  (счётчик игроков + свой ID)
   cef_emit_event(playerid, "hud:online", playerid, GetPlayerPoolSize());
   Слать: при заходе в игру + раз в 30-60 сек (или по событию коннект/дисконнект).

3) hud:ping
   cef_emit_event(playerid, "hud:ping", GetPlayerPing(playerid));
   Слать: таймером раз в 1-2 сек (GetPlayerPing дешёвый вызов, лишней
   нагрузки не даёт).

4) hud:district  (текущий район)
   cef_emit_event(playerid, "hud:district", districtId, districtName);
   Слать: при пересечении границы зоны/района (через существующую
   систему зон, если она уже есть — просто добавить вызов в тот же
   callback, где район меняется сейчас в старом HUD).

5) hud:vitals  (хп / броня / голод)
   cef_emit_event(playerid, "hud:vitals", GetPlayerHealth(...), GetPlayerArmour(...), foodLevel);
   Слать: таймером раз в 1 сек ИЛИ по изменению (событие получения урона,
   лечения, тика голода) — второй вариант эффективнее по трафику.

6) hud:money  (нал / карта / донат-баланс)
   cef_emit_event(playerid, "hud:money", cash, card, donateBalance);
   Слать: по факту изменения (покупка, зарплата, перевод), не таймером —
   деньги меняются редко относительно тика сервера.
   ВАЖНО: банк и депозит из старого HUD в новый макет не влезли (в
   референсе их нет на постоянном экране) — если они нужны, надо либо
   добавить отдельную панель, либо выводить по открытию телефона/банкомата.
   Дай знать, если банк/депозит должны быть видны всегда — добавлю поле.

7) МИНИКАРТА — оставлена нативная (дефолтный радар SA:MP), в CEF не
   выводится. Ничего слать не нужно, hud:minimap событие убрано.
   Позиции панелей: топ-лево (уровень/онлайн) — верхний левый угол,
   топ-право (лого/район/деньги/пинг) — правый край по вертикальному
   центру экрана, виталы (хп/броня/еда) — нижний левый угол, спидометр —
   низ экрана по горизонтальному центру. Все на стандартных CSS-якорях
   (top/left/right/bottom + transform для центрирования), без привязки
   к конкретному разрешению — масштабируются одинаково на любом экране.
   Район (hud:district) остаётся как раньше — просто текстовый бейдж
   рядом с деньгами, без привязки к самой карте.

8) hud:vehicle  (спидометр — только когда игрок в транспорте)
   cef_emit_event(playerid, "hud:vehicle", inVehicle, speedKmh, fuelPct, gearLabel, seatbeltOn);
   - inVehicle   — 1/0, HUD сам скрывает/показывает виджет
   - speedKmh    — реальная скорость (обычно берётся как
                   VectorSize(vx,vy,vz) * 180 из GetVehicleVelocity)
   - fuelPct     — 0-100, нужна текущая система топлива на сервере
                   (если её нет — просто слать 100 или скрыть блок топлива
                   в hud.js/index.html, я уберу если система топлива не
                   используется на проекте)
   - gearLabel   — "P"/"D"/"R" и т.п., если есть система передач; если
                   нет — можно всегда слать "D"
   - seatbeltOn  — 1/0, если есть система ремня безопасности
   Слать: таймером раз в 100-150 мс ПОКА игрок в транспорте (не слать,
   когда пешком — экономит трафик и лишние cef-вызовы).

9) hud:notify  (всплывающие уведомления)
   cef_emit_event(playerid, "hud:notify", text);
   Слать: разово при любом ивенте, который раньше шёл в чат системными
   сообщениями (штраф, получен предмет, ограбление начато и т.п.) —
   на усмотрение серверной команды, HUD просто покажет текст и уберёт
   через 4 сек.


Что НЕ нужно менять на сервере:
- health/armor/food, money, level/exp, online/id, ping, district —
  это те же данные, что и в старом HUD (hud.js v1), просто названия
  событий и наборы аргументов немного другие (см. пункты 1-6 выше) —
  нужно поправить только сами cef_emit_event вызовы под новые имена
  и порядок аргументов, а не придумывать новую логику.

Что нужно добавить с нуля:
- данные о транспорте: скорость/топливо/передача/ремень (п.8), если
  топлива и передач на сервере ещё нет как системы — см. пометку выше,
  эти поля можно временно заглушить константами.
- миникарта отдельно не трогается, карта остаётся нативная от SA:MP
  (см. п.7 выше).

Создание браузера (как и раньше, без фокуса — чтобы не перехватывал
управление):
  cef_create_browser(playerid, BROWSER_HUD, "hud/index.html", false, false);
